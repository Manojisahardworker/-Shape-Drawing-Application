# Shape Drawing Application

## 📌 Overview
An interactive graphics application built in Python that allows users to draw shapes (circle, rectangle, square, triangle) by clicking points in a window. The program calculates dimensions (radius, width, side length) and displays shape details dynamically.

## ⚡ Features
- User input for shape selection
- Interactive drawing with mouse clicks
- Geometry calculations for dimensions
- Real-time display of shape details

## 🛠️ Requirements
- Python 3.8+
- `graphics.py` library (John Zelle’s graphics module)
